# 创作工作台 (Creation Workbench)

AI 视频 + 生图的**执行工作台（二合一）**：一个应用，两个区——
🎬 **视频**：项目 / 分镜 / 生成任务 / 成片与验收；
🖼 **生图**：项目 / 生图任务 / 提示词 / 参考图 / 成图 / 交付 + 画廊。

只做记录与跟踪，**不跑任何生成**（Uppcoder 没有 GPU），不登 Google/Colab，
不走任何隧道/代理/VPN，不碰任何密钥。图在 Colab 里生、视频走 Kaggle / Agnes 队列，
成图成片只记链接，图直接发给用户、由他导进 ToonFlow。

由视频工作台与生图工作台合并而成，同一套零依赖 Node.js 做法。

## 本地运行

```bash
cd creation-workbench
npm install   # 零依赖，这步很快
npm start     # 默认 http://0.0.0.0:3000
```

打开 http://localhost:3000 ，顶部有两个页签：视频（4 个项目）、生图（4 个项目 8 个任务）。

健康检查：`curl http://localhost:3000/api/health` → `{"ok":true,...}`

## 数据

- 视频数据存在 `video.json`，生图数据存在 `image.json`（两个 JSON 文件），
  每次保存都是原子写（先写临时文件再改名）。
- 每个区右上角“导出备份”可下载该区 JSON；“导入”可恢复该区。建议每周各导一份备份。
- 环境变量：`PORT`（默认 3000，Uppcoder 会自己给），
  `VIDEO_DATA_FILE` / `IMAGE_DATA_FILE`（默认 `./video.json` / `./image.json`）。
- 接口：`GET /api/health`、`GET/POST /api/video/state`、`GET/POST /api/image/state`。

## 部署到 Uppcoder Spark（免费档）

前提：Spark 已激活（€0/月、无到期日），含 1 个应用 + 1 个数据库。v1 不用数据库。
**这个合并版只占 1 个应用位**，正好是视频工作台和生图工作台原来要抢的那一个。

1. 把代码推到一个 GitHub 仓库（公开或私有均可），或用 Uppcoder 的上传功能直接传 `creation-workbench` 文件夹。
2. Uppcoder 面板 → 新建应用 → 选 Node.js → 接入上面那个仓库（或上传的代码）。
3. 启动命令：`npm start`（package.json 里已有）。
4. 端口：不用手动设，应用监听 `process.env.PORT`，Uppcoder 会注入；本机测试用 3000。
5. 数据库：v1 不选。以后数据量大了再启用免费 Postgres，把两个 `readState`/`writeState` 换成数据库读写；TigerData 试用（26 天）到期前须把数据迁到 Neon 免费版。
6. 部署完检查：
   - 打开应用给的 HTTPS 地址，应看到顶部“视频 / 生图”两个页签；视频区 4 个项目，生图区 4 个项目。
   - `https://<你的地址>/api/health` 返回 `{"ok":true}`。
   - 在手机上改一个任务状态，刷新页面，改动还在（说明写入磁盘成功）。

## Uppcoder Spark 限制对照

| 限制 | 影响 |
|---|---|
| 2GB 内存 | 本应用常驻约 50–100MB，够用。 |
| 2GB 磁盘 | 两个 JSON 只有几 KB，参考图与成图只存链接不存文件，够用。不要往容器里传图片/视频文件。 |
| 500 CPU 秒/天 | 纯 HTTP 读写，每次请求几毫秒；个人使用一天几百次操作也远不到上限。 |
| 无 GPU | 本工作台本来就不生成，只记录。生成仍走 Colab（生图）/ Kaggle / Agnes 队列（视频）。 |
| 条款 7.1 禁隧道/代理/VPN | 本应用不含任何隧道、代理、VPN 代码；也不要用它转发别的服务。 |
| 容器重启 | 若 Uppcoder 重启容器且磁盘不持久，两个 JSON 可能丢失——所以每周导出备份；长期方案是接免费 Postgres。 |
| 无登录（v1） | 应用地址只有你知道，不要公开分享链接。 |

## 功能

- 视频区：项目列表（新建 / 改名 / 改状态 / 写备注铁律 / 删除）；每个项目：分镜（标题、状态、说明、视频提示词、参考图链接）、生成任务（模型、状态：待排队/生成中/已完成/失败、结果备注）、成片（文件/链接、验收：待验收/已通过/不通过）。
- 生图区：项目列表；每个项目：生图任务（模型默认 Qwen-Image-2.1（Colab）、提示词、参考图链接、成图链接、备注、交付：待发/已发给用户）；画廊集中展示已完成且有成图链接的任务。
- 切换页签不丢位置：回到视频区还是原来打开的项目，生图区还是原来的列表/详情/画廊。
- 修改后自动保存（防抖 600ms），右上角显示保存状态；导出/导入按区独立，互不覆盖。
